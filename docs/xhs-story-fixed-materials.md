## 用户流程

1. 选择模板、内容编辑或 AI 润色，再选择 A/B 配图方案。
2. 独立的感受步骤：查看选定配图，选择实际使用原因和感受。
3. 在同一页面编辑正文、保存原图，确认后复制标题正文和话题。

新版 UI 按已确认设计稿实现：白底、产品紫色 `#7c3aed`、顶部三步进度、大图横向滑动预览与缩略图、底部固定操作区。封面可调整，图片素材继续使用原有 36 张正式 PNG。

不依赖用户简历截图或生成图片接口。图片为产品示例，正文保留模拟数据说明；感受不预选，确认状态不会从上次访问恢复。草稿和配图顺序保存在当前浏览器。

## 重新生成与验证

先启动 `pnpm dev --port 3000`，随后执行：

```sh
pnpm story:capture
pnpm story:generate
pnpm story:verify
pnpm typecheck
pnpm exec vitest run --config scripts/vitest.xhs-note.config.ts
```

捕获和浏览器验证默认使用 `http://127.0.0.1:3000`，可通过 `STORY_BASE_URL` 修改。
