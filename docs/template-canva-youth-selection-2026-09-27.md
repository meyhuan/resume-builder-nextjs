- 建议分类：阶段 `internship` / `graduate`，岗位 `general`，风格 `minimal` / `classic`，布局 `single`，密度暂定 `standard`，语言 `zh`。窄日期栏不按独立内容双栏处理；最终以实现验证为准。

### 为什么保留

原稿实际内容是教育信息、两段校园经历、一段实习、技能证书和荣誉，不依赖主管头衔或多年工作经历撑版。视觉为黑白、细线分区、竖排姓名、紧凑页头；正文沿单一内容流阅读，英文只占很小位置。适合作为克制的中文校招风格候选，不代表所有年轻人都喜欢竖排姓名。

### 与现有模板的真实差异

| 对照 | 相似处 | 候选的具体差异 | 判断 |
| --- | --- | --- | --- |
| 蓝角 `lanjiao` | 窄左侧标题/日期，右侧正文 | 蓝角是淡蓝几何页头、横排姓名、蓝色标题；候选是竖排姓名、黑白细线和连续分隔 | 有视觉选择价值，不是新增信息结构能力 |
| 时间轴 `timeline` | 日期与经历并排 | 时间轴是胶囊箭头章节、图标、局部节点；候选没有大章节横幅，以细线账簿式层级组织 | 不宣称补上时间轴功能 |
| 墨序 `moxu` | 黑白、紧凑、可用于初入职场 | 墨序是黑色联系卡和圆点时间轴；候选是竖向姓名与轻线条页头 | 不是直接复用墨序来源，也不能只凭黑白配色视为全新 |

### 必须先解决的适配问题

1. 原稿将教育信息放进页头；产品不能因此把教育写死、复制一份或剥夺章节拖动。需确认是否允许保留页头气质、把教育继续作为正常可排序模块；若改动导致偏离原稿过大，放弃候选。
2. 竖排姓名须测试四字及更长姓名、英文姓名；不能裁字或强制缩小到不可读。
3. 无头像、少经历、缺少 GPA/荣誉时必须自然收拢；不默认添加年龄、籍贯、排名或虚构证书。
4. 校园经历、证书、荣誉优先映射既有可编辑模块；不为参考图临时添加不可维护的专用字段。
5. 用无实习在校生、一段实习应届生、两段经历年轻社招三个模拟样例比较蓝角/时间轴/墨序。当前尚未执行，不能标为已通过。

**结论：保留供用户审美确认，不直接开工；新增理由是具体视觉选择，而非分类缺口。**

## 3. 收敛后的规划建议

| 场景 | 本轮建议 |
| --- | --- |
| 实习/应届通用 | 现有简约、青柠、一页通继续覆盖；黑白细线款保留 1 个待确认候选 |
| 年轻社招 | 先用浅策、墨序、一页通，不为社招标签额外新增同构版式 |
| 技术工程 | 先用极简黑、一页通；码上仅作现有隐藏项对照，不因此扩大可见性 |
| 产品运营/市场内容 | 先用浅策、紫记、墨序；英文轻策仍是备选，不获自动批准 |
| 正式岗位 | 先用衡简、蓝法、金行 |
| 创意专项 | 视界保持 P2 备选，不放到通用校招主推 |

选择流程：确认具体原稿与可接受的改编边界 → 核实许可 → 补测量/字段映射和统一中文样例对照 → 再逐款实现、完整 QA。未确认的款不因排序靠前而自动实施。
