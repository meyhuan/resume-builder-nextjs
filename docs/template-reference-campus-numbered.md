## 视觉与数据映射

原稿为紧凑单栏，深灰蓝窄条贯穿页顶与页底。顶部左侧姓名和基本信息，右侧矩形证件照。正文从教育、实习、校园经历到自我评价，每节左侧为圆形象形标记，右端为 `01`–`04` 章节序号，下方有细横线；日期、机构和角色用同一行分列，段落以短条目排列。整体是“编号索引 + 紧凑中文经历”，不只是深色标题条。

项目实现中，顶部姓名、字段、头像和求职意向沿用现有编辑能力；所有章节从 `resume.sections` 动态生成，编号由当前顺序计算，增删/拖动后重排。圆章使用原创 CSS 和项目现有通用图标，未复制 Canva 资产。正文不强制一页；长内容与页底色条已进入本地 QA，但真实账号导出仍待发布前复核。
