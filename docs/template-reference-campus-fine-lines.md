## 可观察的视觉结构

原稿为单页 A4、黑白单栏，非通用“蓝色时间轴”换色：顶部以细线围出较紧凑的横向信息区，左侧竖排大姓名，中部个人/联系方式与教育摘要，右侧竖排“个人简历”与照片。正文以横线切分区块；校园与实习经历采用约 1:3 的窄日期栏/宽内容栏，中间细竖线和小圆节点。技能与荣誉回到整行的短条目。装饰很少、强调中文留白和线条节奏。

内部候选按编辑器 A4 宽度实现；当前仅有在线目测，**未完成原稿精确像素测量**，不能声称高保真复刻。

## 与现有款的对照

| 现有模板 | 相同点 | 实质差异/新增价值 | 必须防止的退化 |
| --- | --- | --- | --- |
| `timeline` 时间轴 | 日期与经历可按时间阅读 | 本稿是局部窄日期栏、横线分节和垂直姓名/标题，不是全程彩色时间轴 | 日期栏不得压缩中文职位与公司 |
| `lanjiao` 蓝角 | 日期轴与单栏履历 | 本稿无几何蓝页眉，黑白细线与顶部多列信息是另一种阅读层级 | 不能只是把蓝角变黑 |
| `moxu` 墨序 | 克制黑白、单栏经历 | 墨序的大横排姓名/黑色联系卡不同于本稿的竖排姓名和细线 A4 网格 | 不牺牲长姓名、联系方式与模块排序 |

## 产品化边界

- 不复制原稿照片、图标、字体文件、示例个人信息或整页图。头像由用户上传/隐藏；必要的圆点和直线可由原创 CSS 实现，具体还原程度由用户授权选择决定。
- 教育经历必须仍是正常可排序区块。原稿把教育摘要放在页头，项目模板不能因此把教育写死在页头或丢失全局拖动。
- 竖排姓名只适用于少数字；长姓名和英文名要自适应为横排或换行。无头像时右侧区域应自动收拢。
- 求职意向须可见可编辑；基础信息、自定义字段、模块增删排序、块编辑、AI 操作、主题、移动预览和 PDF 导出必须保留。
- 原稿的信息密度偏高；不能缩小中文正文字号来强行维持一页，长内容自然续页。
