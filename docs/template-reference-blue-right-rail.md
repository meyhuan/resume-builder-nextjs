## 改编方案

左栏为动态排序的教育、工作、项目等经历，右栏为头像、姓名、可编辑求职意向及可移入移出的文字区块。经历类区块保持在宽栏，避免拖入窄栏后可读性下降。联系方式在左栏页首，使用真实基础信息字段；三张固定联系卡不适合动态字段，因此改为自适应字段带。区别于 `warm`、`lifeng` 的左侧信息栏和 `mixu` 的左栏信息 + 大编号，本款主阅读流在左侧，信息栏在右侧，经历用独立浅灰卡片。卡片需允许长中文与 PDF 自然分页。
