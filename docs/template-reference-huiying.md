## 视觉转换

原稿的灰色横向页眉、圆形头像、黑色求职意向胶囊、左灰底联系栏与右经历栏形成视觉基准。产品化时没有纳入原稿的人像、姓名、电话、奖项或技能事实；页面所有个人内容来自简历数据。默认将文本型章节放左栏、经历型章节放右栏，允许编辑时跨栏移动符合条件的章节；长内容自然延伸。灰阶装饰由 CSS 绘制，颜色、字号、间距与页边距随主题调整。

与现有 `lanmu` 等左侧信息栏模板的核心结构接近。本款暂为内部候选，必须用同一份中文简历并排对照阅读性和无头像状态，确认实质差异后才能纳入公开数量。
