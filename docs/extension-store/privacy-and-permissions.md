# 商店隐私与权限填写参考

以下基于当前源码，提交前由发布者逐项核对；不是已完成商店声明或政策合规认证。

## 单一用途（可复制）

帮助用户将已保存的网申资料填写到用户选择的招聘表单，并记录与该次申请相关的投递进度。网页读取和填写由用户主动触发，用户负责核对和提交。

## 权限理由（可逐项复制）

| 配置 | 用途说明 |
| --- | --- |
| `activeTab` | 在用户操作插件时获取当前标签页的临时访问能力，用于确定用户要填写的页面。 |
| `scripting` | 在用户选择且授权的网页中执行包内表单扫描、填写、经历区块新增和提交动作提示逻辑；不代为提交申请。 |
| `storage` | 保存插件授权凭证、引导确认和日期处理偏好；使用会话存储缓存网申资料与当前页填写状态；保存有上限和过期时间的待发送统计。 |
| `identity` | 使用 `launchWebAuthFlow` 与智简简历完成授权回调，复用网站登录状态并避免手动复制凭证。 |
| `sidePanel` | 在网页旁显示连接状态、填写操作、结果和投递确认，使用户能一边核对表单一边操作。 |
| `alarms` | 重试未发送成功的填写效果统计，不用于后台扫描招聘网页。 |
| `https://aijianli.cn/*` | 连接用户账号、读取已保存网申资料、同步投递记录及发送填写效果统计。 |
| 可选 `https://*/*` / `http://*/*` | 用户可能前往不同公司自建的招聘官网，无法预先枚举全部域名。用户点击填写或权限恢复时才请求网页访问权限；只在指定页面执行填写，不自动扫描所有网站。部分网站仍使用 HTTP，隐私说明提醒优先使用 HTTPS。 |

注意：当前权限弹窗申请的是所有 HTTP/HTTPS 网站，不是“只授权当前一个域名”。不要在声明中写成逐站点授权已实现。范围较广仍可能受到审核质询；如审核要求缩小范围，需要实现并回归按站点请求的流程，不能只改文案。

## 数据声明核对表

| 数据 | 流向与用途 | 后台声明要点 |
| --- | --- | --- |
| 姓名、联系方式、经历、求职资料 | 智简简历服务 → 插件会话缓存 → 用户选择的网页 | 涉及个人身份信息与用户提供的内容，不能勾选完全不收集/不处理数据。 |
| 身份证号、健康状况等可选字段 | 仅当用户维护并有匹配字段时用于填写 | 对照后台“健康信息”等分类逐项披露，即使可选，也不能一概声明不涉及。不要引导审核账号录入真实敏感数据。 |
| 授权凭证 | 浏览器本地存储 → 智简简历鉴权接口 | 涉及身份验证信息；不会发送给招聘网站。 |
| 表单标签、选项、已有输入 | 当前页面 → 本机扫描与匹配 | 涉及网页内容读取；不会把原始 DOM、输入正文发送至填写统计接口。 |
| 公司、职位、申请链接、投递状态 | 页面提取/用户确认 → 智简简历投递记录 | 涉及申请页面 URL。不能用“统计不含完整 URL”掩盖业务记录会保存链接。 |
| 插件事件、发生时间、域名、计数、固定失败代码 | 插件 → 智简简历数据库，按部署配置可继续转发产品统计服务 | 涉及使用活动；服务器关联 userId，不是完全匿名。按市场定义核对网页访问/历史相关分类，不能仅因为未调用 history API 就忽略域名和 URL 的处理。 |

源代码依据：

- `extension/entrypoints/background.ts`：资料、填写、记录与事件请求。
- `shared/extension-telemetry.ts`：允许的统计字段及过滤。
- `extension/lib/telemetry-queue.ts`：本机队列最多 100 条、7 天。
- `src/app/next-api/extension/analytics/route.ts`：服务器账号关联与统计转发。
- `src/features/extension-auth/server.ts`：身份与回调白名单。

本机队列的 7 天不是服务器数据的自动删除期限。当前不能声明服务端统计 7 天自动删除；发布者应确认服务端保留期限与删除请求的实际处理流程。断开连接只清本机连接状态，撤销服务端授权应在网站授权管理操作。

## 远程代码

当前填写引擎随插件编译分发，API 读取 JSON 数据，不靠下载远程 JavaScript 执行填写。提交前检查最终包，不仅检查源码；不得混入 CDN 脚本、远程模块或动态执行的远程规则。网站自身的 Next.js 代码不等同于插件加载远程代码。

## 发布者需确认

- 服务端实际部署位置、日志与备份保留期、统计服务是否属于自己的服务。
- 删除账户/资料/统计的请求能实际履行，撤销授权不等于删除这些数据。
- 数据不出售、不用于无关广告等商店承诺必须与实际运营一致，不能由打包脚本代签。
- 部署后的隐私政策与商店填写项一致。

依据：[Chrome 隐私声明](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)、[Edge 隐私声明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension#step-6-enter-privacy-information)。
