# 简历模板覆盖规划

更新：2026-09-19。依据本地模板注册、布局配置和 Canva 搜索页实看；未查询用户埋点，优先级是产品判断，不代表使用量排名。

## 结论

本次盘点时（含青柠，不含随后新增的墨序）编辑器注册 30 款，隐藏蓝芯后可选 29 款；公开目录定义 26 款，隐藏蓝芯后展示 25 款。青云、码上、朱墨、杏坛仅在编辑器注册，公开目录没有对应条目。应先核对展示策略，避免把“入口缺失”误判成“模板缺失”。

已有模板足以覆盖多数中文求职。下一阶段按布局能力和投递情境补缺，暂不设模板数量目标。相同布局的蓝色/紫色变化优先通过主题解决。

## 覆盖矩阵

| 模板家族 | 已有代表（可交叉归类） | 判断与行动 |
| --- | --- | --- |
| 通用单栏 | 简约、星河、浅策、蓝营 | 已覆盖；完善推荐入口 |
| 清爽校招 | 青穗、青云、蓝折、蓝紫、青柠 | 丰富；验证少经历时的留白，不再堆皮肤 |
| 双栏侧栏 | 双栏、砺锋、蓝幕、紫记、商蓝 | 已覆盖；重点看长短栏不均、跨栏拖动和分页 |
| 时间线 | 时间轴、蓝角、密排 | 已覆盖中文履历；英文场景待单独验收 |
| 传统正式 | 表格、衡简、蓝法、金行、典雅 | 已覆盖；银行/法务并不必须各有新布局 |
| 一页紧凑 | 一页通、密排、极简黑 | 已覆盖；关注可读性下限，不一味缩字号 |
| 资深与管理 | 远山 | 有视觉入口；2–3 页长履历、续页和成果展示仍需专项验证 |
| 教师与内容 | 黑教、杏坛、朱墨 | 有视觉入口；不能等同于完整学术 CV 能力 |
| 技术岗位 | 砺锋、码上 | 有布局；技术栈、项目成果主要由内容结构解决 |
| 英文商务 | 无明确独立入口 | P0：新增墨序；验证英文长词、日期、无头像和 PDF 阅读顺序 |
| 学术科研长 CV | 无明确专用能力 | P1：先确认论文/研究/引用等数据结构，再决定是否新模板 |
| 作品展示 | 紫记等仅有风格覆盖 | P2：确认作品链接/图片模块能力后再做，不能靠装饰替代作品内容 |

## 推荐给用户的选择方式

第一层先展示 6–8 个代表：通用、校招、正式、一页、双栏、英文、资深、创意。第二层提供风格选择。过滤条件使用单栏/双栏、信息量、语言、头像；颜色保留为主题控制。

岗位预设与视觉模板分离：岗位决定建议模块顺序、写作问题、成果指标示例和 AI 提示，视觉模板负责排版。预设不自动填入虚构经历或业绩。同一套真实内容可随时换外观。

## 每款模板的进入门槛

来源及 SVG → A4 尺寸与字体分析 → 项目数据映射 → 可编辑组件 → 真实缩略图 → 中英/长短/富文本/移动预览 → 主题与交互 QA → PDF 分页 → 参考对照 → 用户评审。

测试按 docs/template-creation-workflow.md 执行。只有颜色、装饰变化而无明确使用差异的候选，优先不新增。后续恢复数据分析时，比较曝光→选择→首次编辑→成功导出和换回率，再调整默认推荐。
