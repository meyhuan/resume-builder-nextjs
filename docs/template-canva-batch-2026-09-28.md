- 姓名、头像、联系方式、公司、项目、技能和固定示例文案全部由简历数据驱动。
- 参考图只用于测量视觉层级、留白、栏宽、标题节奏和色彩关系；实现复用项目现有 ResumeFrame、AvatarSlot、FieldChip、SortableSection、BlockList 与编辑钩子。
- 2026-10-01 复核发现：此前实现复用了通用布局，不能凭 24 个 ID 或旧 QA 报告认定为 24 款不同设计。现已按真实参考图重做结构，使用 `_canva` 下的版式配方及共享编辑组件；简擎与极简黑同构而隐藏，由章序替换名额。23 款本批公开改编 + 章序 + 4 款存量共 28 组原稿/成品已查看；最终 50 款运行 QA 与封面、150 份 PDF 共 200 页的本地技术/视觉验收通过。真实环境与来源人工项仍未完成，尚未部署。
