# 教育填写建议的数据来源

核验日期：2026-10-03。

- 学校：教育部《全国高等学校名单》，截至 2026-06-17。`schools.json` 提取附件中的学校名称和所在地，共 2952 所普通高等学校，包含本科及高职专科学校，不包含成人高校及港澳台、海外学校。
  - 发布页：https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202606/t20260618_1441074.html
  - 原始附件：https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202606/W020260618416094865984.xls
  - 字段：学校名称（第 2 列）、所在地（第 5 列）；只提取第 1 列为数字序号的行。
- 专业：教育部《普通高等学校本科专业目录（2026 年）》中的常见本科专业名称。
  - 原始附件：https://www.moe.gov.cn/srcsite/A08/moe_1034/s3882/202604/W020260427440749576927.pdf

学校简称是独立维护的搜索别名；歧义简称保留多个候选，不自动选中。所在地用于辨认学校，不表示用户实际就读的校区。

这些数据用于辅助填写，用户始终可以保存自己的原文，包括历史校名、海外学校、专科或研究生专业。选择学校不修改城市、专业或学历。
